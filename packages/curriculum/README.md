# Curriculum package

Single source of truth for the lesson pack.

- `curriculum.json` — 15 illustrative bilingual lessons (pilot board: **CBSE**)
- `bands.json` — age bands `koko` (K–5), `nova` (6–8), `principal` (9–12)
- `schema/lesson.schema.json` — JSON Schema (`board` required, default CBSE)

Copies under `apps/web/curriculum.json` and Android `assets/www/` are generated by `npm run sync` — do not edit them by hand.
